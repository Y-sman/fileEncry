## 一、需求概述

### 1.1 当前系统现状

| 功能 | 状态 |
|------|------|
| 用户RSA密钥对生成与管理 | ✅ 已有 |
| 个人文件AES加密上传/解密下载 | ✅ 已有 |
| 用户间文件分享 | ❌ 缺失 |
| 即时通讯 | ❌ 缺失 |
| 好友关系管理 | ❌ 缺失 |

### 1.2 目标功能

实现 **"用户A获取用户B公钥 → 用户A加密上传 → 通过聊天分享给用户B → 用户B用自己的私钥解密下载"** 的完整流程

## 二、功能需求清单

### 2.1 功能模块总览

| 模块 | 功能点 | 优先级 |
|------|--------|--------|----------|
| **好友系统** | 添加好友、好友列表、在线状态 | P0 |

### 2.2 详细功能需求

#### 模块1：好友系统

| 序号 | 功能 | 描述 | 验收标准 |
|------|------|------|----------|
| 1.1 | 搜索用户 | 按用户名/昵称搜索站内用户 | 支持模糊搜索，显示搜索结果列表 |
| 1.2 | 发送好友申请 | 向指定用户发送添加好友请求 | 对方收到申请通知，数据库记录申请 |
| 1.3 | 处理好友申请 | 同意或拒绝好友申请 | 同意则建立双向好友关系，拒绝则记录状态 |
| 1.4 | 好友列表 | 查看所有好友，显示在线状态 | 列表展示，在线用户标识绿色圆点 |
| 1.5 | 删除好友 | 解除好友关系 | 双向删除，相关分享失效 |
| 1.6 | 获取好友公钥 | 获取好友的RSA公钥用于加密 | 接口返回Base64编码的公钥 |

#### 模块2：即时通讯

| 序号 | 功能 | 描述 | 验收标准 |
|------|------|------|----------|
| 2.1 | WebSocket连接 | 建立长连接，实时消息推送 | 连接稳定，支持断线重连 |
| 2.2 | 发送文本消息 | 好友间发送文字消息 | 消息实时送达，显示发送时间 |
| 2.3 | 接收消息 | 实时接收好友消息 | 新消息弹窗提示，未读消息数角标 |
| 2.4 | 历史消息 | 查看与某好友的聊天记录 | 分页加载，支持向上滚动加载更多 |
| 2.5 | 消息已读 | 标记消息为已读状态 | 对方看到已读标识 |
| 2.6 | 在线状态 | 显示好友是否在线 | 好友上线/下线实时通知 |

#### 模块3：文件分享

| 序号 | 功能 | 描述 | 验收标准 |
|------|------|------|----------|
| 3.1 | 分享文件给好友 | 选择文件和好友进行分享 | 生成分享记录，密钥重加密 |
| 3.2 | 聊天内分享文件 | 在聊天窗口直接发送文件 | 显示文件卡片，点击可下载 |
| 3.3 | 查看分享给我的文件 | 列表展示所有收到的分享 | 显示分享者、文件名、分享时间 |
| 3.4 | 查看我分享的文件 | 列表展示所有发出的分享 | 可查看分享状态，支持撤销 |
| 3.5 | 撤销分享 | 取消已发出的文件分享 | 接收方无法再下载 |
| 3.6 | 下载分享的文件 | 用私钥解密下载 | 校验完整性，解密后下载原文件 |

```sql
    INDEX idx_owner (owner_id, status),
    INDEX idx_file (file_id)
) COMMENT='文件分享表';
```

### 5.3 核心代码框架

#### 5.3.1 文件分享服务 - 密钥重加密

```python
# owl_encry/service/enc_file.py 新增方法

@classmethod
def share_file_to_user(cls, file_id: int, target_user_id: int) -> int:
    """
    将文件分享给指定用户 - 核心：密钥重加密
    
    流程：
    1. 获取文件信息
    2. 用当前用户私钥解密出AES密钥
    3. 用目标用户公钥重新加密AES密钥
    4. 保存分享记录
    
    Returns:
        share_id: 分享记录ID
    """
    from owl_encry.service.enc_user_key import EncUserKeyService
    from owl_common.utils import security_util
    from owl_encry.mapper.file_share_mapper import FileShareMapper
    from owl_encry.domain.entity import FileShare
    
    current_user_id = security_util.get_user_id()
    
    # 1. 获取文件信息
    enc_file = cls.select_by_id(file_id, current_user_id)
    if not enc_file:
        raise ServiceException("文件不存在或无权访问")
    
    # 2. 获取当前用户私钥，解密出原始AES密钥
    private_key = EncUserKeyService.get_private_key_pem(current_user_id)
    if not private_key:
        raise ServiceException("您尚未生成RSA密钥对")
    
    aes_key = CryptoService.rsa_decrypt(private_key, enc_file.sym_key_enc)
    
    # 3. 获取目标用户公钥
    target_public_key = EncUserKeyService.get_public_key_pem(target_user_id)
    if not target_public_key:
        raise ServiceException("对方尚未生成RSA密钥对，无法分享")
    
    # 4. 用目标用户公钥重新加密AES密钥
    new_sym_key_enc = CryptoService.rsa_encrypt(target_public_key, aes_key)
    
    # 5. 创建分享记录
    share = FileShare(
        file_id=file_id,
        owner_id=current_user_id,
        target_user_id=target_user_id,
        sym_key_enc=new_sym_key_enc,
        permissions='READ',
        status=0
    )
    
    return FileShareMapper.insert(share)
```

#### 5.3.2 WebSocket服务框架

```python
# owl_chat/socket_server.py

from flask_socketio import SocketIO, emit, join_room, leave_room
from flask import request

socketio = SocketIO(cors_allowed_origins="*")

@socketio.on('connect')
def handle_connect():
    """用户连接"""
    user_id = get_user_id_from_token(request)
    join_room(f"user_{user_id}")
    
    # 通知好友上线
    friends = get_friend_ids(user_id)
    for fid in friends:
        emit('friend.online', {'user_id': user_id}, room=f"user_{fid}")

@socketio.on('chat.message')
def handle_message(data):
    """处理聊天消息"""
    sender_id = get_user_id_from_token(request)
    receiver_id = data.get('receiver_id')
    content = data.get('content')
    msg_type = data.get('msg_type', 1)
    
    # 保存消息
    msg_id = save_message(sender_id, receiver_id, content, msg_type)
    
    # 推送给接收者
    emit('chat.receive', {
        'msg_id': msg_id,
        'sender_id': sender_id,
        'content': content,
        'msg_type': msg_type,
        'create_time': now()
    }, room=f"user_{receiver_id}")
```

```python
# controller/friend/friend.py

from flask import request
from owl_common.base.model import AjaxResponse, TableResponse
from owl_common.descriptor.serializer import JsonSerializer
from owl_common.descriptor.validator import QueryValidator, PathValidator
from owl_framework.descriptor.permission import PreAuthorize, HasPerm
from .. import reg
from ...service import friend_service

@reg.api.route("/friend/search", methods=["GET"])
@PreAuthorize(HasPerm("friend:list"))
@JsonSerializer()
def search_users():
    """搜索用户"""
    keyword = request.args.get('keyword', '')
    users = friend_service.search_users(keyword)
    return AjaxResponse.success(data=users)

@reg.api.route("/friend/request", methods=["POST"])
@PreAuthorize(HasPerm("friend:add"))
@JsonSerializer()
def send_friend_request():
    """发送好友申请"""
    data = request.get_json()
    request_id = friend_service.send_request(
        to_user_id=data.get('to_user_id'),
        message=data.get('message', '')
    )
    return AjaxResponse.success(msg="申请已发送", data={"request_id": request_id})
```

### 8.3 WebSocket客户端模板

```javascript
// utils/socket.js

import io from 'socket.io-client'

class ChatSocket {
  constructor() {
    this.socket = null
    this.connected = false
  }
  
  connect() {
    this.socket = io(process.env.VUE_APP_SOCKET_URL + '/ws/chat', {
      transports: ['websocket'],
      auth: {
        token: getToken()
      }
    })
    
    this.socket.on('connect', () => {
      this.connected = true
      console.log('WebSocket connected')
    })
    
    this.socket.on('disconnect', () => {
      this.connected = false
    })
  }
  
  sendMessage(receiverId, content, msgType = 1) {
    this.socket.emit('chat.message', {
      receiver_id: receiverId,
      content: content,
      msg_type: msgType
    })
  }
  
  onReceiveMessage(callback) {
    this.socket.on('chat.receive', callback)
  }
  
  onFriendOnline(callback) {
    this.socket.on('friend.online', callback)
  }
}

export default new ChatSocket()
```

## 十、注意事项

### 10.1 开发注意事项

1. **密钥安全**：私钥解密操作必须在服务端完成，不要传递到前端
2. **WebSocket鉴权**：连接时验证token，防止未授权访问
3. **SQL注入**：所有数据库操作使用参数化查询
4. **并发处理**：文件分享时考虑并发情况下的数据一致性

### 10.2 测试账号准备

准备2-3个测试账号，确保都生成了RSA密钥对，用于测试文件分享流程。
